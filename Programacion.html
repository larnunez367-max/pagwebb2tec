¿Qué es programar?

Programar es escribir instrucciones precisas, en un lenguaje que la computadora pueda entender, para resolver un problema o automatizar una tarea. Todo lo que usas a diario, como una app de mensajes, un videojuego o una página web, es un programa escrito por personas.

Antes de escribir una sola línea de código, un programador piensa en un algoritmo: los pasos ordenados que llevan de un problema a su solución. La computadora hace exactamente lo que se le pide, ni más ni menos, por eso los errores (llamados bugs) forman parte del trabajo diario.

Practica un bucle: FizzBuzz

Es un ejercicio muy famoso en entrevistas de programación. Se cuenta del 1 hasta el número que elijas: si es múltiplo de 3 se escribe "Fizz", si es múltiplo de 5 se escribe "Buzz", y si lo es de ambos, "FizzBuzz".

for (let i = 1; i <= n; i++) {
                if (i % 15 === 0) salida = "FizzBuzz";
                else if (i % 3 === 0) salida = "Fizz";
                else if (i % 5 === 0) salida = "Buzz";
                else salida = i;
}
Presiona "Ejecutar" para ver el resultado.

Glosario de programación

Algoritmo
Conjunto de pasos ordenados y finitos para resolver un problema. Una receta de cocina es un algoritmo.
Variable
Espacio con nombre donde el programa guarda un dato que puede cambiar, como el puntaje de un juego.
Bucle (loop)
Estructura que repite un bloque de instrucciones varias veces, ya sea un número fijo o mientras se cumpla una condición.
Condicional
Estructura que permite al programa tomar decisiones: "si pasa esto, haz aquello; si no, haz otra cosa".
Función
Bloque de código con nombre que realiza una tarea y se puede reutilizar cuantas veces se necesite.
Bug
Error en un programa que produce un resultado inesperado. Encontrarlos y corregirlos se llama depurar (debugging).
API
Interfaz que permite que dos programas se comuniquen entre sí, por ejemplo una app del clima que pide datos a un servidor.
Git
Sistema de control de versiones que guarda el historial de cambios del código y facilita trabajar en equipo.

Pon a prueba lo que aprendiste

1. ¿Cómo se llama el conjunto de pasos ordenados para resolver un problema?

Un algoritmo describe los pasos a seguir, y luego se traduce a un lenguaje de programación.

2. ¿Qué estructura se usa para repetir instrucciones?

Los bucles (for, while) repiten un bloque de código sin tener que escribirlo muchas veces.

3. ¿Qué lenguaje se usa para consultar bases de datos?

SQL significa Structured Query Language (lenguaje de consulta estructurado).
